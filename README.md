# planificador-estudio-cloud
Plataforma nativa de la nube para la planificación académica personalizada.

## Problema que resuelve

Los estudiantes necesitan organizar asignaturas, entregas y sesiones de estudio, pero una lista de tareas no siempre les indica qué deberían estudiar primero ni cómo distribuir el tiempo disponible.

## Solución propuesta

Una aplicación web que permita registrar asignaturas y tareas, calcular prioridades y generar un plan de estudio adaptado al tiempo disponible.

## Tecnologías previstas
- Backend: Python con FastAPI.
- Comunicación: API REST mediante HTTP y JSON.
- Persistencia: una base de datos.
- Despliegue: un proveedor de servicios en la nube.

## Funcionalidades principales
1. Gestionar asignaturas.
2. Crear y modificar tareas con fechas límite, dificultad e importancia.
3. Consultar las prioridades de estudio.
4. Generar y actualizar un plan de estudio.
5. Consultar el progreso.
